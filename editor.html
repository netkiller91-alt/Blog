글쓰기

여기서 쓴 글은 저장소에 커밋되고, 배포 워크플로가 자동으로 사이트에 반영합니다. 반영까지 보통 1분쯤 걸립니다.

1. GitHub 토큰

Fine-grained 토큰을 만들어 붙여넣으세요. 권한은 이 저장소 하나에 대해 Contents: Read and write만 있으면 됩니다.

토큰은 이 브라우저 밖으로 나가지 않고 GitHub API 외에는 어디로도 전송되지 않습니다. 공용 PC라면 저장하지 마세요.

2. 내용

마크다운 일부를 지원합니다 — ## 제목, **굵게**, *기울임*, `코드`, ```블록```, - 목록, 1. 번호, > 인용, [링크](주소), ---

3. 미리보기

본문을 입력하면 여기에 표시됩니다.

4. 발행

커밋 3건이 생성됩니다 — 글 파일 추가, 홈 목록 갱신, RSS 갱신.
